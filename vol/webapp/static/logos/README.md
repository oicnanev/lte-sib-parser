# Operator logos (optional, not in git)

Put operator logos here, named by PLMN (MCC-MNC), to show them in the web
app's PLMNs column instead of the coloured name badges:

    268-01.svg   (or .png, .webp, .jpg)
    268-03.png

Any PLMN works (e.g. 214-07.svg for a Spanish network). Height is scaled to
16 px. Everything but this README is ignored by git: logos are the operators'
trademarks and the repository is public. Reload the page after adding files.
